# تغییرات یادمان v1.2.0

## ۱) سرعت و رفع لگ بین صفحات
علت اصلی لگ پیدا شد: موتور تکرار برای هر یادآور، در هر صفحه و هر ۳۰ ثانیه، تا ۸۰۰ روز را روزبه‌روز می‌گشت و در **هر روز** دوباره تاریخ ISO و meta_json را پارس می‌کرد و یک SimpleDateFormat تازه می‌ساخت. صفحه اقساط هم این محاسبات را روی نخ اصلی (UI) انجام می‌داد.

| اصلاح | فایل |
|---|---|
| کش پارس تاریخ ISO | `utils/DateUtils.kt` |
| `dayKey` بدون ساخت SimpleDateFormat | `utils/DateUtils.kt` |
| کش خواندن meta_json و done_dates (هر رشته فقط یک‌بار پارس می‌شود) | `data/ReminderMeta.kt` |
| موتور تکرار: ماهانه/سالانه ماه‌به‌ماه (نه روزبه‌روز)، توقف فوری بعد از end_at، محاسبه base/end/done یک‌بار | `utils/Recurrence.kt` |
| همه ViewModelها محاسبات را روی `Dispatchers.Default` انجام می‌دهند (اقساط، خرید، یادداشت، اعلان‌ها، پروفایل) | `ui/screens/*` |
| انیمیشن جابه‌جایی صفحه کوتاه‌تر (۱۵۰/۱۰۰ms) | `ui/navigation/NavGraph.kt` |
| **Release با R8 + shrinkResources** و امضای debug برای نصب مستقیم | `app/build.gradle.kts`, `proguard-rules.pro` |
| `profileinstaller` برای Baseline Profileهای Compose | `libs.versions.toml` |

> ⚠️ مهم: نسخه **debug** اپ‌های Compose ذاتاً ۲ تا ۵ برابر کندتر است. برای استفاده روزمره حتماً `assembleRelease` بگیرید:
> `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`

## ۲) بخش جدید «اشتراک‌ها»
- نوع جدید `subscription` (دسته `cat_subscription`، رنگ `#FF8F5C`، آیکن `YIcons.Subscription`)
- صفحه `SubscriptionsScreen.kt`: هزینه ماهانه/سالانه معادل، تعداد تمدید نزدیک، دکمه «تمدید شد»/«برگرداندن»، نگه‌داشتن = حذف
- دسترسی: کاشی «اشتراک‌ها» در هاب خانه (با بج) + کارت در تب «یادآوری‌ها» + نوع «اشتراک» در فرم یادآوری جدید
- اعلان: «تمدید اشتراک …» با دکمه «تمدید شد»
- meta: `{"type":"subscription","plan":"فیلیمو خانوادگی"}` — سینک: record_type = `reminder`
- دسته جدید برای نصب‌های قبلی خودکار اضافه می‌شود (`Seed.ensureCategories`)

## ۳) تعداد دفعات تکرار (مثلاً ۱۰ قسط)
- در فرم یادآوری جدید، وقتی تکرار ≠ یک‌بار باشد، فیلد «تعداد دفعات» ظاهر می‌شود (خالی = نامحدود) و تاریخ آخرین قسط را پیش‌نمایش می‌دهد.
- ذخیره: `meta_json.total_count = N` و `end_at = پایان روزِ وقوع N-ام`.
- نتیجه: بعد از آخرین قسط هیچ وقوع، آلارم یا یادآوری دوباره‌ای ساخته نمی‌شود. اگر آخرین قسط را «پرداخت» بزنید، آلارم فوراً لغو و کارت «تسویه شد 🎉» می‌شود و به ته لیست می‌رود.
- کارت قسط: چیپ «قسط ۳ از ۱۰»؛ متن اعلان: «قسط ۳ از ۱۰» / «آخرین قسط!»
- گزینه تکرار «سالانه» هم به فرم اضافه شد.
- API جدید در Recurrence: `nthOccurrence`, `lastOccurrence`, `occurrenceIndex`؛ در ReminderMeta: `int`, `totalCount`.

## محدودیت
- یادآورهای قبلی تعداد ندارند (صفحه ویرایش هنوز نیست). برای قسط لوازم خانگی: کارت قبلی را نگه دارید → حذف، و از نو با «تعداد دفعات» بسازید (تاریخ شروع = قسط بعدی، تعداد = اقساط باقی‌مانده).
- این تغییرات بدون Android SDK نوشته و ایستا بررسی شده‌اند؛ اگر بیلد خطا داد، متن خطا را بدهید.
